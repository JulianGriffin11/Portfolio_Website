I make complex data simple. I am a statistics graduate working as an AI Engineer, Data Analyst, and in Data Science, with experience in data, analytics, financial information, and business operations.

## Keep it simple

Simple enough that another person can explain the result without a walkthrough. Accuracy depends on that clarity: clear sources, plain rules, and a result someone else can check.

Clarity is the check. A named source, a plain rule, and a result another person can point at are what make the work finished.

## Stack

The site uses TypeScript, React, Next.js, and Tailwind CSS. TypeScript holds the content, React and Next.js render it, and Tailwind CSS styles it.
